# 🐢 Turtle Soup AI · 海龟汤推理小游戏

一个基于 Spring Boot + 原生前端的海龟汤网页小游戏，  
引入大语言模型（通义千问）作为裁判，实现自然语言提问、胜利判定与完整游戏流程。

本项目为 Java 课程设计作品。

---

## 🎮 游戏玩法

- 系统随机给出一道「汤面」
- 玩家通过提问，根据 AI 回答的 **是 / 否 / 无关** 逐步推理真相
- 当你认为已经复盘出完整故事，可选择「我知道答案了」进行猜测
- AI 将基于语义理解进行胜利判定

---

## ✨ 功能特性

- 🤖 AI 裁判（是 / 否 / 无关）
- 🏁 AI 语义级胜利判定
- 📜 游戏日志记录（写入 logs/ 目录）
- 🔁 题目不重复轮换
- 🎨 深夜汤馆主题 UI（移动端适配、动效）
- 🛡 统一 JSON 响应与全局异常处理
- 🧪 单元测试（14 个用例）
- 📦 一键启动脚本 start.bat

---

## 🚀 快速开始

1. 安装 JDK 17（https://adoptium.net/temurin/releases/?version=17）
2. 设置环境变量 `DASHSCOPE_API_KEY` 为你的通义千问 API Key
3. 打包：`mvnw.cmd package`（Windows）或 `./mvnw package`（Mac/Linux）
4. 双击 `start.bat`（Windows），浏览器访问 http://localhost:8080

> 更详细的图文说明见 [使用说明.md](使用说明.md)
